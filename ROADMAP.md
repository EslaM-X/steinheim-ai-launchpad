# Roadmap

## North star

> A marketing OS where every AI-generated claim can be traced to a verified
> fact in the Steinheim knowledge base — and no post ships without a human.

## Sequenced next

1. **More verified content** — grow the fact-checked knowledge base that
   feeds the agents (products, certifications, project references).
2. **Agent quality** — keep tightening the plan/write/illustrate/check
   pipeline; every improvement is verified against real Steinheim material.
3. **Workflow hardening** — improve the n8n orchestration and the human
   approval gate so daily production stays reliable.
4. **Distribution** — document how the content ships across channels, and
   measure engagement per claim.

## Explicitly out of scope (for now)

- Generic AI text generation without fact-checking. The core rule is
  enforced in code: every claim traces to a fact.
- Fabricating product data or references.
