# Steinheim AI Marketing System — النسخة الأولى

نظام تسويق ذكي لعلامة Steinheim (أنظمة حمامات ألمانية فاخرة في مصر — مجموعات Joy / Up / Art / Quatro، وعملاء: مطورون، ضيافة، مصممون، تجارة). كل شيء داخل هذا التطبيق: قاعدة معرفة + لوحة تحكم + توليد محتوى بالذكاء الاصطناعي. الواجهة ثنائية اللغة (عربي RTL / إنجليزي LTR) مع زر تبديل.

## 1. تفعيل الباك-إند (Lovable Cloud)

قاعدة بيانات + تسجيل دخول + تخزين صور، بدون حسابات خارجية. الدخول بالبريد وكلمة المرور، وكل صفحات الإدارة محمية.

## 2. قاعدة المعرفة (الجداول)

- `brand_profile` — هوية Steinheim: نبرة الصوت، الرسائل الأساسية، ممنوعات، لغات.
- `categories` — الفئات/المجموعات (Joy, Up, Art, Quatro...).
- `products` — الاسم، الكود، الفئة، الوصف، الخامات/التشطيبات، المميزات، السعر التقريبي، الرابط.
- `product_images` — صور المنتجات (تخزين داخلي + وصف بديل).
- `audiences` — العملاء المستهدفون (مطور عقاري، مقاول، فندق، مصمم داخلي، مستهلك نهائي) مع نقاط الألم والدوافع.
- `projects` — المشاريع المرجعية (اسم، موقع، دولة، صور، منتجات مستخدمة).
- `content_ideas` — أفكار المحتوى: الموضوع، الهدف (بيع/توعية/علامة)، المنتج، الجمهور، التاريخ المقترح، الحالة.
- `posts` — المنشور النهائي لكل منصة (LinkedIn / Facebook / Instagram)، النص، الهاشتاجات، وصف الصورة، الصورة، الحالة (مسودة/مراجَع/معتمد/منشور)، وقت الجدولة.
- `post_analytics` — انطباعات، تفاعل، نقرات، ليدز لكل منشور.
- `agent_runs` — سجل تشغيل كل وكيل (المدخلات، المخرجات، الوقت) للتتبع.

كل الجداول عليها صلاحيات وسياسات أمان: القراءة والكتابة لأعضاء الفريق المسجَّلين فقط.

بيانات أولية داخل الهجرة: ملف العلامة، المجموعات الأربع، جمهورين أو ثلاثة، وعدد من المشاريع المرجعية — حتى تكون اللوحة مليانة من أول فتح.

## 3. وكلاء الذكاء الاصطناعي (داخل التطبيق)

كل وكيل دالة على السيرفر تستخدم Lovable AI وتقرأ من قاعدة المعرفة:

1. Content Strategist — يختار موضوع اليوم + الهدف + المنتج + الجمهور، ويكتبه في `content_ideas`.
2. Research Agent — يضيف زوايا وحجج وإحصاءات مناسبة للفكرة.
3. Copywriter — يكتب LinkedIn (مهني) + Facebook (تسويقي) + Instagram Caption + هاشتاجات، بالعربي والإنجليزي.
4. Image Prompt Agent — يكتب وصف الصورة بأسلوب Steinheim البصري، مع إمكانية توليد الصورة فعليًا.
5. Reviewer — يراجع الالتزام بنبرة العلامة ودقة معلومات المنتج ويعطي درجة وملاحظات.
6. Analytics Agent — يلخص الأداء ويقترح تحسينات.

زر واحد **Generate Today** يشغّل السلسلة كاملة ويعرض التقدم خطوة بخطوة.

## 4. لوحة التحكم (الصفحات)

- **Overview** — مؤشرات: منشورات هذا الشهر، معدل التفاعل، أفضل منشور، زر Generate Today.
- **Products** — إدارة المنتجات والفئات والصور (إضافة/تعديل/حذف).
- **Knowledge** — ملف العلامة، الجماهير، المشاريع.
- **Content Calendar** — عرض شهري/أسبوعي للأفكار والمنشورات حسب الحالة.
- **Post Editor** — تعديل نص كل منصة، الصورة، ملاحظات المراجع، ثم Approve.
- **Publish** — قائمة المعتمَد؛ زر Publish يسجّل المنشور كـ "منشور" ويحفظ الرابط (النشر الآلي للمنصات يأتي في مرحلة لاحقة عند ربط Meta/LinkedIn).
- **Analytics** — إدخال/عرض أرقام الأداء ورسوم بيانية.
- **Logs** — سجل كل المنشورات وكل تشغيل للوكلاء.

## 5. الجاهزية للأتمتة و n8n لاحقًا

- نقاط اتصال عامة محمية بمفتاح سري تحت `/api/public/…` لتشغيل التوليد اليومي وسحب المحتوى الجاهز.
- بهذا يقدر n8n (على الموبايل أو VPS لاحقًا) يستدعي النظام الساعة 9 صباحًا بدون إعادة بناء أي شيء.

## تفاصيل تقنية

- TanStack Start + Lovable Cloud (Postgres + Auth + Storage) + Lovable AI (`google/gemini-3.6-flash`) عبر server functions.
- التبديل بين العربية والإنجليزية عبر مزوّد لغة يضبط `dir` و`lang`، والنصوص في ملفات ترجمة.
- تصميم يعكس هوية Steinheim: أبيض/رمادي فاتح، أسود فحمي، لمسة نحاسية، خطوط راقية ومساحات واسعة — لا ألوان بنفسجية عامة.
- النشر الفعلي على Meta/LinkedIn وتوليد الفيديو والشات بوت خارج نطاق هذه المرحلة.

## ما بعد الموافقة

نبدأ بالباك-إند وقاعدة المعرفة والبيانات الأولية، ثم لوحة التحكم، ثم الوكلاء وزر Generate Today.
